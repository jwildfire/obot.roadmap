    where every number came from
    

    
  
      
    
    • The order and the one-line reason — rank/top10.json in
      jwildfire/obot.agent, the single declared store.
      It holds an order and a reason and nothing else, by test.
      • 
    
    • Membership — the top10 and on-deck labels on
      jwildfire/obot.roadmap, one API call each.
      • 
    
    • Title, state, milestone, sub-issue progress, blocked — derived from GitHub at build time,
      read 2026-08-21 00:23. None of it is written into this page by hand, and a field
      GitHub did not answer for is printed as unanswered rather than left blank.
      • 
    
    • The history — every commit that has touched rank/top10.json, with the store's
      bytes at that commit asked for directly rather than replayed from a patch. A commit whose store
      will not parse produces a frame that prints its reason; nothing is filled in for it.
      • 
    
    • The membership timeline — GitHub's labeled and unlabeled issue events
      for the two labels, 4 pages of them.
      This is the only part of this page that reaches back past the store's first commit.
      • 
    
    • Two clocks, never merged — how old the order is comes from the commit that last touched the
      file, never the file's timestamp, which a fresh clone stamps with the moment it was written. How old
      the state beside it is comes from when GitHub last answered.
