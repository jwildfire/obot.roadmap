01

Two things this screen refuses to do

It never pre-fills a guess

Identical names bind on request and are marked identical. Everything else stays a proposal, printed in the row, until a person clicks it — and the click is recorded in the YAML as # accepted proposal. A data manager who finds one wrong pre-filled row stops trusting the other 125, and re-checking 126 rows by hand is worse than filling them.

It never shows a confidence number

Candidates are ordered and the reason for the order is printed. No score. The guided-setup session measured a value profiler scoring 1.000 on a wrong answer and 0.849 on a right one, on the study open.gismo ships. There is no threshold that admits one and rejects the other, so the number would only transfer the machine's certainty to the reader.

02

What is real on this screen

  • The left-hand side. 45 target columns with their declared types, read out of demo-301/workflows/1_mappings/{SUBJ,AE,LB}.yaml this morning.
  • The consumer counts. Resolved from the 42 metric and module workflows. Mapped_SUBJ$subjid carries 25, $invid and $country 12 each, Mapped_LB$lbtstnam and $lbstresn 7 each, $toxgrg_nsv 3.
  • The two spec keys. gsm.mapping::ApplySpec reads source_col and type and nothing else, and drops any spec entry whose source column is absent from the file — silently, at every verbosity level. That is the entire seam this screen writes into.
  • The key measurement. Reproduced on demo-301's own data this session: the long identifier and the short one share 0 of 765 values, and the inner join the study runs returns 0 rows from 57,200.
  • The delivered column names are constructed — a CRO transport, an EDC event listing and a central-lab extract, written from the CDISC and EDC-vendor conventions. The match rate you see is therefore an upper bound on a real one, which is survivable only because nothing here is ever applied without a click.

The argument for this surface, and the honest case against it, are on the recommendation — grafts G4 to G7, and weakness W1. The path that reaches it is the flow.
