# open.gismo v0.2.0 — annotated demo

Walkthrough of what open.gismo v0.2.0 delivers, built as the review surface for the v0.2.0 release-candidate PR (dev → main) under the RC framework. Captures taken 2026-08-15 with Playwright against the live [DEMO-301 deployment](https://jwildfire.github.io/demo-301/) (built end to end by this release's engine). Sections: the study site, RBQM ranked scores beside the funnel, the denominators-first Safety domain, provenance + snapshot time travel, and the local-first engine (`og_init` → `og_validate` → `og_run` → `og_view`).

Media: 2× JPEG stills under `media/`. DEMO-301 is a synthetic study — no real participant data.
